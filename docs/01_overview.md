# 01. 서비스 개요

## 1. 무엇을 만드는가

**ハレの日ポスト** — 「ハレの日(특별한 날)」에 받을 메시지를 모아 두는 우체통 서비스.

1. 회원이 기념일을 골라 **포스트**를 만든다.
2. 포스트 링크(`/post/{code}`)를 SNS 등으로 공유한다.
3. 링크를 받은 사람은 **로그인 없이** 카드를 써서 넣는다.
4. **개봉일**이 되면 주인만 카드를 열어 읽을 수 있다. 그 전에는 몇 통 왔는지만 보인다.

## 2. 사용자

| 사용자 | 설명 |
|---|---|
| 방문자 | 로그인하지 않은 사람. 카드 보내기, 회원가입 |
| 회원 | 포스트 만들기·꾸미기, 카드 열어보기·신고, 마이페이지 |
| 관리자 | `ROLE_ADMIN` 회원. 신고 처리, 카드 디자인 관리 |

## 3. 테마(기념일)

| 코드 | 화면 표시 | 개봉일 | 배경 | 대표 아이콘 |
|---|---|---|---|---|
| `SHOGATSU` | お正月 | 다음 1월 1일 0:00 (고정) | 후지산, 해돋이, 매화, 안개 띠 | 鏡餅 |
| `BIRTHDAY` | 誕生日 | 회원 생일 0:00 기본값, 변경 가능 | 가랜드, 풍선, 케이크 | 케이크 |
| `CHRISTMAS` | クリスマス | 다음 12월 25일 0:00 (고정) | 트리, 눈, 선물 | 트리 |

- "다음" = 오늘(JST) 이후 가장 가까운 날짜. 예: 2026-10-12에 만들면 お正月 → 2027-01-01 00:00
- 誕生日: 회원 생일이 있으면 다음 생일 0:00을 기본값으로 넣고, 회원이 날짜·시간을 바꿀 수 있다(오늘 이후 1년 이내). 생일이 없으면 직접 고른다.

## 4. 우체통 꾸미기

- 우체통 색: **빨강 고정**(색 선택 기능 없음)
- 장식: 테마마다 3개, 슬롯은 지붕 위(top)·앞(front)·옆(side). 여러 개 동시 선택 가능(0~3개)
- 이름표: 우체통 몸통에 표시, 최대 8자
- 다른 테마의 장식은 고를 수 없다(서버에서 검사)

| 테마 | top | front | side |
|---|---|---|---|
| SHOGATSU | `KAGAMI` 鏡餅 | `SHIMEKAZARI` しめ飾り | `KADOMATSU` 門松 |
| BIRTHDAY | `HAT` とんがり帽子 | `RIBBON` リボン | `BALLOON` 風船 |
| CHRISTMAS | `SANTA` サンタ帽 | `WREATH` リース | `PRESENT` プレゼント |

장식 SVG와 배경 SVG는 `design/js/theme-art.js` 에 이미 있다(`THEMES`, `DECOS`, `BG`, `THEME_ICONS`, `drawBackground`, `drawDecos`). 그대로 `static/js/` 로 옮겨 쓴다.

## 5. 용어

| 용어 | 뜻 |
|---|---|
| 포스트 (post) | 카드를 받는 우체통 하나. 주인 1명, 테마 1개, 개봉일 1개 |
| 코드 (code) | 포스트 공유용 무작위 8자 문자열. URL에 쓰임 |
| 카드 (card) | 방문자가 넣는 메시지. 보낸 이름 + 본문 + 카드 디자인 |
| 카드 디자인 (design) | 관리자가 올린 카드 배경 이미지. 테마 전용 또는 공통 |
| 개봉일 (open_date) | 이 시각 이후에만 주인이 카드 본문을 볼 수 있음 |
| 수신 마감 | 개봉일이 지나면 새 카드를 받지 않음 |
