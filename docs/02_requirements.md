# 02. 요구사항 (HP-REQ-01, 2026-10-12 개정)

> 개정 내용: お盆 제외, クリスマス 추가, 우체통 색 선택 삭제(빨강 고정), 장식 여러 개 선택

## 기능 요구사항

### REQ-F-01 회원가입 / 로그인 / 프로필
- 아이디·패스워드로 로그인한다(Spring Security formLogin).
- 회원가입 시 아이디, 패스워드, 닉네임, 이메일, 생일(선택)을 등록한다.
- 회원가입 전에 **아이디 중복 확인**과 **이메일 인증(6자리 코드)** 을 완료해야 한다.
- 마이페이지에서 프로필과 내 포스트 목록을 본다. 닉네임/이메일/생일/패스워드를 수정하거나 탈퇴할 수 있다.

### REQ-F-02 포스트 생성
- 기념일(お正月, 誕生日, クリスマス) 중 하나를 골라 포스트를 만든다.
- 개봉일 기본값: お正月 = 다음 1/1 0:00(고정), クリスマス = 다음 12/25 0:00(고정), 誕生日 = 다음 생일 0:00(변경 가능).
- 만들면 무작위 8자 코드가 들어간 공유 링크를 발급한다.

### REQ-F-03 포스트 꾸미기
- 주인은 테마 장식(최대 3개, 여러 개 동시 선택)과 이름표(최대 8자)를 고른다. 우체통 색은 빨강 고정.
- 저장 전에 미리보기로 확인하고, 저장하면 모든 방문자에게 반영된다.

### REQ-F-04 포스트 화면과 공유
- 테마 배경, 포스트 이름, 개봉일, 개봉까지 남은 시간, 받은 카드 수를 보여 준다.
- 받은 카드는 봉투(보낸 이름 + 디자인)로만 표시하고 본문은 보여 주지 않는다.
- 링크 복사 버튼으로 공유한다.

### REQ-F-05 카드 보내기
- 링크를 받은 사람은 로그인 없이 카드 디자인을 고르고 이름과 메시지를 써서 보낸다.
- 보내면 새로고침 없이(ajax) 포스트 화면에 봉투가 늘어난다.
- 개봉일이 지난 포스트에는 보낼 수 없다. 같은 IP는 1분에 1장.

### REQ-F-06 개봉과 카드 열람
- 개봉일 이후 주인은 로그인해서 카드 본문을 읽는다.
- 연 카드는 읽음 처리한다. 부적절한 카드는 신고할 수 있다.

### REQ-F-07 포스트 관리
- 주인은 개봉 전에 포스트 이름, 기념일, 개봉일을 바꾸거나 포스트를 삭제할 수 있다. 기념일을 바꾸면 장식은 초기화된다.
- 포스트를 지우면 카드와 신고도 함께 지워진다.

### REQ-F-08 관리자
- 카드 디자인 이미지를 등록하고 사용 여부·표시 순서를 관리한다.
- 신고된 카드를 확인하고 삭제하거나 처리 완료로 바꾼다.
